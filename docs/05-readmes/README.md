| Archivo | Descripción |

| `README-server.md` | Guía rápida de ejecución del servidor (JSON Server) y del cliente (Vite). |

| `../plan-tecnico.md` | Plan técnico del proyecto. |
| `../04-guia-modularizacion.md` | Guía de modularización de la arquitectura. |
| `../reporte-tecnico.md` | Reporte técnico del proyecto. |
